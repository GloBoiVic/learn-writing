# Sentence Anatomy

**subject → finite verb → object / complement + modifiers**

| Find first | Why |
| --- | --- |
| Finite verb | It locates a clause core and lets you count clauses. |
| Subject | It reveals who or what carries the sentence grammatically. |
| Objects and complements | They show what the action affects or what the subject becomes. |
| Modifiers | They add precision but can create ambiguity when detached. |
