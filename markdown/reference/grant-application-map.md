# Grant Application Map

**funder question → direct answer → specific evidence → credible measure**

| Field | Reader needs to see |
| --- | --- |
| Need / population | Defined condition, affected people, local evidence, relevance, and limits. |
| Project | Who will do what, for whom, where, when, and why it is feasible. |
| Capacity / collaboration | Operational evidence and distinct partner roles. |
| Outputs / outcomes / evaluation | Work completed, expected change, indicator, method, timing, and limitations. |
| Budget / sustainability | Necessary use of funds and credible continuation conditions. |
| Whole application | Consistent population, geography, scope, terms, numbers, timeframe, and level of promise. |
